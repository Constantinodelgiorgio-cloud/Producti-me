# 02 · Datos necesarios

Regla general: **cada dato debe servir para una decisión o para motivarme**. Si no, no se registra.

Leyenda de prioridad: **P1** = imprescindible para el MVP · **P2** = segunda fase · **P3** = opcional/avanzado.
Leyenda de captura: **M** = manual · **A** = automático (reloj, móvil, apps) · **F** = foto · **IA** = inferido.

---

## C. Datos derivados (los calcula la app)

| Indicador | Cómo se calcula |
|---|---|
| **Puntaje por área (0–100)** | Promedio ponderado de cumplimiento de hábitos + progreso hacia metas + métricas subjetivas del área. Pesos editables. |
| **Puntaje de vida** | Promedio ponderado de áreas según mis prioridades actuales. |
| **Consistencia** | % de días con hábitos mínimos cumplidos (ventana 7/30 días). |
| **Correlaciones personales** | Relación entre pares de variables con ≥ 21 días de datos (ej. sueño ↔ foco, entreno ↔ ánimo). |
| **Tendencia** | Media móvil 7 y 30 días; flecha ↑ ↓ →. |
| **Riesgo de abandono** | Hábito con cumplimiento cayendo 2+ semanas → sugerir simplificar. |
| **XP / nivel** | Puntos por acción ligada a objetivo (si activo la gamificación). |

## D. Check-in diario mínimo (el corazón del MVP)

**Mañana (~20 s)**
1. ¿Cuántas horas dormiste? / calidad 1–5
2. Energía 1–5
3. Ánimo 1–10
4. Prioridad n.º 1 del día

**Noche (~60 s)**
1. Hábitos cumplidos (lista de checks)
2. Ánimo y estrés 1–10
3. ¿Se cumplió la prioridad? sí / parcial / no
4. Una victoria + una frase libre (opcional por voz)

Con solo esto, en 3–4 semanas ya hay datos para las primeras correlaciones.

## E. Fuentes automáticas posibles (para reducir carga manual)

| Fuente | Datos |
|---|---|
| Apple Health / Google Health Connect | pasos, sueño, frecuencia cardíaca, peso |
| Reloj (Garmin, Apple Watch, Fitbit, Whoop, Oura) | sueño, HRV, entrenamientos |

| Strava / app de gimnasio | entrenamientos |
| Banco / export CSV | gastos |
| Tiempo de pantalla del móvil | uso de redes |

Qué dispositivos y apps uso es una de las preguntas clave del cuestionario.

## F. Privacidad de los datos

Los datos de ánimo, salud, fotos corporales y finanzas son **muy sensibles**:
- Guardarlos cifrados y, si es posible, solo en mi dispositivo o en mi propia nube.
- Fotos de progreso fuera de la galería general del móvil.
- Copia de seguridad exportable (JSON/CSV) bajo mi control.
- Si se usa IA en la nube, enviar resúmenes, no datos crudos, y saber qué se envía.
